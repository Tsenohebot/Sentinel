# SENTINEL — Global Intelligence Platform

A single-page real-time intelligence dashboard that aggregates live flight tracking, satellite orbits, maritime shipping, financial markets, global news, weather, traffic, and conflict zone data onto an interactive dark-themed world map.

Built as a single HTML file (~2,200 lines) with no build step. Drop it on any static host and go.

## Features

### Live Flight Tracking ✈️
- Real-time aircraft positions via **adsb.lol** (free, no key, no rate limits)
- Multi-point grid queries that scale with zoom level — from 1 query at city zoom to 9 at global view
- Auto-refetches on pan and zoom with debounced requests
- Click any aircraft for callsign, altitude, speed, heading, and aircraft type

### Satellite Tracker 🛰
- Tracks ~20 satellites including ISS, CSS Tianhe, Hubble, GOES, NOAA, Landsat, and Starlink
- TLE orbital data from **CelesTrak**, propagated client-side using **satellite.js** (SGP4/SDP4)
- ISS gets special treatment: dashed green orbit prediction line (~90 min ahead)
- Positions update every 5 seconds, list refreshes every 10 seconds

### Maritime Shipping 🚢
- 8 simulated container/bulk carrier routes across major global trade lanes
- Animated ship positions with heading indicators
- Click for vessel details: IMO, flag, TEU capacity, route, status

### Financial Markets 📈
- Live stock quotes and market news via **Finnhub** (free tier)
- Auto-refreshing ticker display with price change indicators

### Intelligence Feed 📡
- **Global tab**: World news from Finnhub + GNews with region filtering (N. America, Europe, Mid East, Asia Pacific, Africa)
- **Local tab**: Country-specific news — click anywhere on the map to auto-detect the country via reverse geocoding and fetch local headlines
- Defaults to UK on startup
- Severity-coded headlines (crisis/risk/normal)

### Conflict Zones ⚠️
- 25 curated conflict zones across 4 severity levels (critical, high, moderate, watchlist)
- Animated SVG pulse markers with severity-coded colors
- Click any zone for detailed popup: conflict type, start date, casualty info, description
- **Live data mode**: auto-fetches `conflict_zones.json` generated by the GDELT scraper (see below)
- Falls back to static data if live fetch fails

### Weather & Location Info 🌤
- Click anywhere on the map for instant weather via **Open-Meteo**
- Wikipedia integration: nearest city/town info with description and article link
- Reverse geocoding via **Nominatim** (OpenStreetMap)

### Traffic Overlay 🚗
- Live traffic flow tiles from **TomTom** (free tier: 50K tiles/day)
- Color-coded congestion: green (free flow) → red (heavy)
- Toggle on/off from the toolbar

### Map Layers
- **Dark** — minimal dark tiles (default)
- **Street** — detailed street map with buildings and POIs
- **Satellite** — aerial imagery
- Layer controls centered at bottom of screen

## Automated Conflict Zone Updates

The dashboard can load live conflict zone data scraped from the **GDELT 2.0 Event Database** — a free, open, real-time global event monitor that processes news in 100+ languages every 15 minutes.

### How it works

```
GitHub Actions (cron every 6h)
    │
    ▼
update_conflicts.py
    │  1. Downloads GDELT event exports (CSV)
    │  2. Filters for CAMEO conflict codes (14, 17-20)
    │  3. Clusters events geographically (DBSCAN, 150km radius)
    │  4. Scores severity: events(40%) + media(30%) + Goldstein(20%) + tone(10%)
    │
    ▼
conflict_zones.json  ──committed to repo──▶  GitHub Pages serves it
    │
    ▼
sentinel-live.html   ──fetches on load──▶  Live overlay on map
```

### Setup

The workflow runs automatically once the files are in the repo. No manual steps needed.

1. Ensure these files are in your repo root:
   - `update_conflicts.py`
   - `.github/workflows/update-conflicts.yml`
2. Go to Settings → Actions → General → Workflow permissions → **Read and write**
3. Done. The first run fires within 6 hours, or trigger it manually from the Actions tab.

### Severity levels

| Level | Score | Color | Typical triggers |
|-------|-------|-------|-----------------|
| Critical | ≥ 100 | Red | Active war, mass violence, 200+ events |
| High | 40–99 | Orange | Sustained armed conflict, 80+ events |
| Moderate | 15–39 | Yellow | Insurgency, tensions, 30+ events |
| Low | < 15 | Blue | Watchlist, sporadic incidents |

## Tech Stack

**Frontend** (all in one HTML file):
- **Leaflet** — interactive map with multiple tile layers
- **satellite.js** — SGP4/SDP4 orbital propagation for satellite tracking
- **Orbitron + JetBrains Mono** — fonts
- Vanilla JS, no frameworks, no build tools

**Data sources**:
- adsb.lol — ADS-B aircraft transponder data
- CelesTrak — satellite two-line element sets
- Finnhub — financial market data and news
- GNews — regional news headlines
- TomTom — traffic flow raster tiles
- Open-Meteo — weather forecasts
- Wikipedia — location info via geosearch + REST API
- Nominatim (OSM) — reverse geocoding
- GDELT — global event monitoring for conflict zones

**Automation**:
- Python 3.11 + pandas + scikit-learn (DBSCAN)
- GitHub Actions for scheduled scraping

## Configuration

All configuration is done through the in-app modal (⚙ CONFIG button). Two modes:

- **▶ GO LIVE** — connects to all APIs with your keys for real-time data
- **▶ SIMULATE** — generates synthetic data for demo/offline use

Toggle individual layers on/off from the header toolbar:
`✈ FLIGHTS` · `🚢 SHIPPING` · `📡 NEWS` · `📈 STOCKS` · `🛰 SATS` · `🚗 TRAFFIC` · `⚠ CONFLICTS`
